# Screenshot Guide

Use this folder for GitHub, marketplace, and documentation screenshots.

## Recommended Captures

- `status-command.png`: `/parcel status` with healthy polling state.
- `delivery-log.png`: sanitized console output for a successful delivery.
- `queued-delivery.png`: a queued online-only delivery waiting for a player.
- `config-highlight.png`: cropped `config.yml` with the token redacted.

## Capture Notes

- Always redact API tokens, order IDs if private, player UUIDs if needed, and private server details.
- Do not show a full private store dashboard unless all sensitive data is hidden.
- Prefer a test package and test player for public screenshots.
- Keep images at least 1280px wide when possible.

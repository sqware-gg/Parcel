# Changelog

All notable changes to this project will be documented here.

## 2.1.0 - 2026-05-25

Public repository release.

### Added

- Webstore delivery polling for Bukkit, Spigot, and Paper servers.
- Console command execution for paid package delivery.
- Online-only delivery queueing.
- Durable queued delivery and pending confirmation state.
- Order idempotency checks.
- Heartbeat payloads with server and delivery state.
- Local retry for delivery confirmations.
- Shaded Gson dependency.
- GitHub Actions build workflow and release jar.
